A simple, step-by-step picture guide. In about 2 minutes, you'll give Perplexity live access to all 27 of your Bytescon government-contracting tools.

★ 5 EASY STEPS · ~2 MINUTES

Before you start

  • A Perplexity paid plan — custom connectors require Pro, Max, or Enterprise.
  • Your Bytescon access token — in the Bytescon app go to Settings → MCP Access → Generate Access Token and copy it (shown only once).
  • The connector address (Step 2):
    https://bytescon.com/mcp
1

Open Perplexity's Connectors

Click your profile → Account Settings → Connectors.

Connectors are saved to your account — set up once.

2

Add a custom remote connector

Click + Custom connector, then choose Remote. Fill in:

• Name: Bytescon
• MCP Server URL: https://bytescon.com/mcp
• Authentication: OAuth.

Check the acknowledgement box and click Add.

If something goes wrong

  • Don't see "Custom connector": it requires a Perplexity Pro, Max, or Enterprise plan.
  • Error mentioning "client_secret": this is a known Perplexity-side quirk with public connectors — not a problem on the Bytescon side. Email support@bytescon.com and we'll help.
  • Token rejected: generate a fresh one in Settings → MCP Access → Generate Access Token and paste the latest.
