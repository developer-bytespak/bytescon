# Glossary — What the Words Mean

Words are grouped. Each has a **kid-friendly** meaning first.

## Government contracting words

| Word | Simple meaning | More precise |
|------|----------------|--------------|
| **Federal contract** | A deal where the US government pays a company to do a job | Legally binding agreement under the FAR |
| **Solicitation / RFP / RFQ** | The government's "job wanted" note | Request for Proposal / Quote |
| **Opportunity** | A job you could try to win | A posted solicitation or notice |
| **Proposal / bid** | Your "pick me" letter | The written offer, usually technical + price volumes |
| **Award** | Winning the job | Contract given to the selected offeror |
| **Prime contractor** | The main company that wins | Holds the contract directly with the government |
| **Subcontractor ("sub")** | A helper company working for the prime | |
| **Teaming** | Companies joining forces to bid | Teaming agreement / joint venture |
| **Capture** | Getting ready to win before the job is posted | Pre-RFP relationship and strategy work |
| **Pipeline** | Your list of jobs you are chasing | Stages: identified → qualified → capture → proposal → submitted → won/lost |
| **Bid / No-bid** | Deciding "try" or "skip" | Go/no-go decision |
| **Gate review** | A checkpoint where a boss says "continue?" | Formal approval step |
| **Incumbent** | The company doing the job now | Current contract holder |
| **Re-compete** | The same job being offered again | Follow-on solicitation |
| **Amendment** | A change to the job note | Official modification to a solicitation |
| **Set-aside** | Jobs reserved for certain small businesses | Competition restricted by SBA program |
| **SDVOSB** | Small business owned by a veteran hurt in service | Service-Disabled Veteran-Owned Small Business |
| **WOSB** | Small business owned by women | Women-Owned Small Business |
| **HUBZone** | Small business in an area that needs more jobs | Historically Underutilized Business Zone |
| **8(a)** | SBA program helping disadvantaged owners | SBA 8(a) Business Development |
| **NAICS code** | A number saying what kind of work you do | North American Industry Classification System |
| **PSC** | A code for what is being bought | Product Service Code |
| **UEI** | A company's ID number with the government | Unique Entity ID (replaced DUNS) |
| **CAGE** | Another company ID code | Commercial and Government Entity code |
| **SAM.gov** | The government's main website for jobs and company registration | System for Award Management |
| **USAspending** | Website showing who got paid what | Public federal spending data |
| **FPDS** | The record book of past contracts | Federal Procurement Data System |
| **Grants.gov** | Website for government grants (gifts of money for projects) | |
| **E-Rate** | Program paying for school and library internet | USAC Schools & Libraries program |
| **FAR / DFARS** | The big rule books for buying | Federal Acquisition Regulation / Defense supplement |
| **Section L / Section M** | "How to write your letter" / "How we will grade it" | Instructions / Evaluation criteria |
| **Compliance matrix** | A checklist of every rule in the job note | Requirement-to-response mapping |
| **Past performance** | Proof you did similar work well before | CPARS / references |
| **CLIN** | A line item on the contract | Contract Line Item Number |
| **Option period** | Extra years the government may add | Contract option |
| **Modification** | A change to a signed contract | Contract mod |
| **Deliverable** | Something you must hand in | Report, product, or service milestone |
| **Period of performance** | How long the job lasts | |
| **DCAA** | The auditors who check your time and money records | Defense Contract Audit Agency |
| **Indirect rates** | Extra costs added on top of salaries (benefits, office, admin) | Fringe, overhead, G&A |
| **Incurred cost** | What you actually spent | Annual incurred-cost submission |
| **SF-424** | Standard grant application form | |
| **SBLO** | Prime's small-business contact person | Small Business Liaison Officer |
| **CMMC / NIST 800-171** | Cybersecurity rules for defense contractors | |

## Bytescon product words

| Word | Simple meaning |
|------|----------------|
| **Firm / tenant** | A consulting company that uses Bytescon. Its data is walled off from other firms |
| **Client company** | A small business the firm helps |
| **Pursuit** | One opportunity the firm is actively chasing for a client |
| **Win probability** | The honest guess of your chance to win (0–100%) |
| **Calibration** | Adjusting the guess using your real past results so "60%" really means 6 out of 10 |
| **Agent** | A robot helper that checks things on a timer |
| **Artifact** | A report an agent writes |
| **Escalation** | An agent raising its hand: "a person needs to decide this" |
| **Add-on / module** | A paid extra feature |
| **Proposal token** | A coin you spend to get AI proposal help |
| **Client portal** | The client company's own login area |
| **Partner portal** | The subcontractor's own login area |
| **Attestation** | A person promising "I checked the AI's writing" |
| **Monitoring profile** | A saved search that alerts you |

## Tech words

| Word | Simple meaning |
|------|----------------|
| **Frontend** | The part of the app you see |
| **Backend / API** | The part that does the work behind the scenes |
| **Database** | Where all information is stored |
| **Queue / worker** | A line of jobs and the helpers that do them in the background |
| **SaaS** | Software you use through the web and pay for monthly |
| **Multi-tenant** | Many companies share one system but can't see each other's data |
| **JWT / token** | A digital pass that proves who you are |
| **MFA** | Second check when you log in (code from your phone) |
| **SSO** | Log in using your company's main account |
| **RBAC** | Different people get different permissions |
| **LLM** | The AI brain that reads and writes text (like Claude) |
| **MCP** | A standard way for AI assistants (Claude, ChatGPT) to plug into Bytescon |
| **Webhook** | Another service tapping Bytescon on the shoulder to say "something happened" |
| **Feature flag** | An on/off switch for a feature |
| **Migration** | A safe, recorded change to the database structure |
| **Audit log** | A diary of who changed what and when |
| **PWA** | A website you can install like a phone app |
